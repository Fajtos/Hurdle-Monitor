# Parts E to H: calibration, power, PITMonitor comparison and panel study

Each part has its own protocol in `data/` (`protocol_E.md` to `protocol_H.md`). The protocol files and the scripts of a part are committed and tagged before the part is run: `protocol-E-frozen`, `protocol-G-frozen`, `protocol-H-frozen`. The protocol and script of Part F were committed after its run. A frozen file is not edited after its tag.

All commands are run from the project root. In an R console use `source("application/NN_name.R")`.

## Packages

`pscl` and `digest`, in addition to the packages in `renv.lock`.

## Interrupting and resuming

Scripts 12 to 15 keep finished jobs on disk. If a run is interrupted, running the same `source(...)` line again continues from the finished jobs.

## Smoke tests

Setting `Sys.setenv(FA_SMOKE = "1")` runs a script on two windows and writes to a separate folder (`pitmon_smoke` for script 14, `panel_smoke` for scripts 15 and 16). Reset with `Sys.setenv(FA_SMOKE = "0")` before a full run. Two outputs of a smoke test are expected and are not faults:

- Script 14 prints `NaN (not competitive)` for the ratio of net detections, because with two windows the net detection of PITMonitor is zero and the ratio is zero over zero.
- Script 16 stops after `0 origins with at least 3 complete series`, because a panel needs at least three series at the same origin and two windows cannot give that. The error that follows comes from printing the decision lines on an empty summary. It does not occur in the full run.

## Known label in Part G

In a full run the net detection of PITMonitor can be zero, so the ratio in `decision_G.txt` is infinite and the script prints `not competitive`. The rule fixed in the protocol is that the headwise e-detector is competitive if its net detection is at least 0.8 times that of PITMonitor. With a PITMonitor net detection of zero the rule is met if the e-detector net detection is not below zero. The numbers in `pooled.csv` are the result; the printed label is not.

## Not committed

The trajectory files in `out/events/panel/traj/` are intermediate and are listed in `.gitignore`, as are the smoke test folders. They are regenerated by `15_panel_trajectories.R`.

- Each script reports the number of jobs against the number expected and the number of model fit warnings in `run_log.txt`.
